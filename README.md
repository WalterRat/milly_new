# milly_new
Bot for discord

Бот работает только на slash-командах, поэтому привилегированные intents (Message Content, Server Members, Presence) не нужны.

## Команды

Для администраторов:
- `/alloch #канал` — разрешить боту принимать команды в канале
- `/disalloch #канал` — убрать канал из списка
- `/givemaster @участник @роль` — назначить участника мастером роли
- `/rmmaster @участник` — снять статус мастера

Для мастеров (только в разрешённых каналах):
- `/giverole @участник` — выдать свою роль
- `/rmrole @участник` — забрать свою роль

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

При приглашении бота нужны scope `bot` и `applications.commands`, а также право Manage Roles. Роль бота должна стоять выше выдаваемых ролей. После первого запуска slash-команды могут появиться в Discord с задержкой до часа.
